# PayPal Test Agent

An AI agent that generates and runs test scenarios against the PayPal Sandbox
and explains failures in plain English. Built for the PayPal AI Hackathon.

## Setup
1. Python 3.10+
2. `python -m venv venv` then activate it
   (Windows: `venv\Scripts\activate`)
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and add your PayPal **sandbox** credentials
5. `python first_call.py` should print an order ID
